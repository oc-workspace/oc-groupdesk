# 2026-11-23

## 范围与决策

按用户要求在 Apple Silicon Mac（arm64）上开发并构建**不依赖 Docker 的 macOS 原生独立安装包**，供本机直接测试，同时沿用 RC6 的干净白名单发行边界与零私有数据隔离契约。本次在开发分支 `feat/macos-native-package-20261123` 推进，不修改线上生产容器，也不触碰 `rococo-root` 生产发布流程。

关键决策：
- 基于现有 `scripts/package-standalone.py` 白名单源码包作为上游输入，确保不携带数据库、上传素材、聊天记录、账号、Key、私人 Persona 或第三方 Skill。
- 原生包内置独立 Node.js 运行时（`v24.22.3`，验证仅依赖 macOS 系统库）与可重定位 PostgreSQL 16（`16.11`，递归重定位全部 Homebrew 动态库至 `@loader_path` 并完成 ad-hoc `codesign`），目标 Mac 无需预装 Docker、Homebrew、Node 或 PostgreSQL。
- `server/index.ts` 支持 `process.env.HOST || '0.0.0.0'`，Docker 模式行为保持不变，macOS 原生模式默认绑定 `127.0.0.1` 回环地址；私有 PostgreSQL 亦仅监听 `127.0.0.1` 随机独立端口且关闭 Unix Socket 目录以避免 macOS 104 字节路径上限。
- 提供双击可用的 `GroupDesk.app`（封装在 `.dmg` 中，首次运行自动引导初始化并打开网页，运行中提供打开网页/查看日志/停止服务弹窗）以及命令行 `.tar.gz` 包。

## 完成内容

- `server/index.ts`：监听地址改为 `process.env.HOST || '0.0.0.0'`。
- `distribution/manage-macos.py`：新增 macOS 原生独立实例生命周期与加密备份/恢复工具（`init`/`up`/`down`/`status`/`logs`/`backup`/`restore`/`open`/`launchd-install`/`launchd-uninstall`），保持 `0700`/`0600` 权限、非空目标防覆盖、后台 worker 默认关闭、`--isolated` 禁启 worker 及恢复对账契约。
- `distribution/README-macos.md`：补充免 Docker macOS 原生图形化与命令行安装使用说明。
- `scripts/package-macos-native.py`：新增 macOS 原生离线打包脚本，自动校验干净源码包、预构建前后端与生产依赖、打包独立 Node 与可重定位 PostgreSQL 16、纯 Python 生成 `.icns` 图标与 `GroupDesk.app`、输出 `.tar.gz` / `.dmg` / `SHA256SUMS` / `macos-package-result.json`。
- `tests/test_standalone.py`：扩展覆盖 `manage-macos.py` 的路径穿越/链接拒绝、清单篡改检测、白名单校验及 Node 版本校验。
- `docs/standalone-distribution.md`：补充 macOS 原生免 Docker 包的交付物、校验值与实机验收边界。
