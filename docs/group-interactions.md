# 群互动、娱乐积分与兑换

后台侧栏「群互动」提供互动模板、群内配置、积分与兑换三个页面。模板可创建、人工修改、归档和恢复；各群独立勾选，修改需要保存，机器人确认状态只在人工刷新后更新。

## 每日摸鱼

首版内置「每日摸鱼」。每群独立记账；默认每人每天一次，均匀随机获得1—100个娱乐积分token，不是API额度、现金或加密资产。日界线默认Asia/Singapore。每日次数为本群所有签到模板共用，不能通过启用多个模板重复领取。可配置奖励区间、次数、时区、点名要求、命令、回复语言及文案模型。

支持中文、英文、日文、韩文、法文、西班牙文、德文默认命令；回复跟随当前命令语言，也可选择沿用群语言策略。自然语言咨询由普通聊天模型结合本群公开玩法指导回答；签到与扣分只认整条命令，不从普通对话推测操作。命令和别名支持人工维护，引用、长句及普通含关键词的聊天不当作签到。

中文示例：`摸鱼`或`签到`；查分`余额`；查奖品`兑换列表`或`可以兑换啥`；申请`兑换 R001`。英文为`check in`、`balance`、`prizes`和`redeem R001`。固定奖品编号与列表显示序号不同，调整排序不会兑错奖品。

## 奖品与履约

不预设真实奖品。空列表回复「现在还没定奖品，可以找群主商量」，GT风格带一点轻松调侃，不承诺群主提供飞吻等礼物。管理员确定奖品后设置固定编号、名称、描述、积分成本、有限或不限库存和启停状态；每群最多启用10项。

查询时输出编号列表、所需token和具体兑换命令。申请在数据库事务中预留积分与有限库存；后台「积分与兑换」确认兑换才扣积分，随后人工标记交付。拒绝或取消释放预留，已确认但取消返还积分；已交付不可直接取消。审核不会自动给群发消息。历史申请保存当时奖品与价格，调价不改变旧申请。

账本不删除；管理员可按原因增减积分，网络重试不会重复调整。余额不能低于已预留积分。当前微信UI桥接只有群内昵称，昵称派生标识不是稳定微信账号：改名或同名可能拆分或合并账户，需要管理员核对和有记录地调整；实际兑奖应人工核验。未来可信适配器可提供稳定账号标识，不能仅凭聊天内容声称身份。

## 文案模型与扩展

每个群的每个互动可沿用本群文字模型、从API Key与文本模型联动下拉框独立选择，或禁用AI只用基础文案。选中的模型生成按语言、结果、Persona、指令及模型版本区分的可复用文案模板；首次触发立即使用基础文案，后台准备好后复用。模型不接收当前成员身份、余额、奖品详情或原始聊天；数额、奖品和命令由程序填入，严格校验占位符，失败继续用基础文案。

每日互动回复默认1000、每分钟20、同人间隔3秒；AI文案默认每日20次、单次90秒。这是独立互动限额，普通MaiBot对话预算保持原值。物理发送仍共用原桥接锁；页面可改这些值，不自动轮询。未启用互动的群不受影响。

除签到外，首版支持「自定义文字互动」：定义完整触发词、基础回复与文案目标，不改积分。新的复杂玩法需要新增处理器和契约版本，不能通过提示词执行任意代码或改账。基础回复由管理员维护；多语言自定义内容应为各语言分别建模板和触发词。

## 运行、备份与回滚

数据库迁移009增加互动定义、配置、账户、日领取计数、事件、奖品、申请、账本、每日用量与文案缓存表。旧数据不自动启用互动或添加奖品。事件源标识幂等，按群加锁；奖励、预留和库存同一事务提交。发送前单独预留，重启/发送状态不确定时不自动重发。积分已入账但回复失败时仍可查询余额，管理员能看发送状态。

Compose新增`interaction-worker`；它只负责模板生成，需要外网和原有加密密钥。不要更换`MODEL_ENCRYPTION_KEY`。备份与恢复脚本先停止文案worker，再停止app与普通worker，完整保存数据库、文件、发布SHA与根用户可读的加密恢复密钥。恢复前校验摘要；失败保持停止。

原生安装脚本`integration/maibot/interactions/install-interactions.py`只处理核对过的桥接锚点，摘要不符拒绝；重复安装字节相同。将共享`interactions_runtime.py`放入limits，更新groupdesk_runtime，再安装桥接钩子。先备份并等待无活动请求，只重建MaiBot与桥接，不能重启微信。新原生端兼容无互动契约的旧后台；启用互动后，后台仅接受真实应用`interactions_policy_version=1`的ACK。

回滚旧应用前先停`interaction-worker`（旧Compose不认识此服务，要用当前版本停止或显式移除该容器），禁用群互动并确认机器人同步，再回滚应用/原生代码。迁移为新增表，保留账本，不直接DROP生产数据。完整恢复使用发布前备份及配套加密密钥，回退会丢失备份后的新账，须人工核对。

验证使用独立tmpfs PostgreSQL和固定MaiBot镜像的断网副本；不向真实群发送测试消息，也不在生产写入示例积分账户或奖品。
