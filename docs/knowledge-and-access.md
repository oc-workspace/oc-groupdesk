# 知识库与成员权限

知识库支持人工文字与UTF-8 TXT/Markdown、文字型PDF上传。后台任务处理成功后生成可检索片段；处理失败有状态与原因，允许人工重试。扫描图片PDF需要先OCR。当前检索是关键词检索，包含中文双字匹配，不是向量检索或模型微调。

只有当前群明确关联且处理就绪的知识库进入该群检索。素材内容是参考资料，不能作为执行命令。缺少活动、地点等依据时应说明未知，不用其他群资料填补。

私聊先用可信、可跨会话验证的稳定成员ID核验，再选择群场景。一个人可属于多个群，但当前会话只选择一个场景；切换场景清理旧上下文。昵称派生的ui-标识仅用于群内，不足以核验私聊成员；不能只凭“我是某群成员”授权。

成员撤销、退出、群停用或私聊场景过期后重新拒绝资料访问。身份验证和检索在服务端检查，适配器失联或权限请求失败时不能使用旧缓存继续回答。

多机器人模式下，知识库、文件、处理任务、成员授权和私聊场景均属于所选机器人；相同昵称或用户ID不授予另一个机器人的权限。具体接口与能力契约见[runtime-api.md](runtime-api.md)。
