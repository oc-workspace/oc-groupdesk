# 页面自动更新盘点（2026-11-19）

按当前开发/线上基线核对。范围为浏览器自动读取服务器数据；页面首次加载、用户保存/提交后的即时重读，不作为后台定时轮询。

本次仅删除群聊总结页面的10秒定时请求，并统一手动刷新提示。保留首次加载、右下角“刷新任务与配置”和操作成功后的重读。后台总结执行、自动发布计划、群命令、发送恢复和消息采集均不在本次修改范围。

## 其他仍保留的页面自动更新（未修改）

| 位置 | 触发及频率 | 停止条件 | 源码 |
| --- | --- | --- | --- |
| 知识库 → 管理资料 | 当前知识库有 pending/processing 资料时，每3秒读取资料及索引状态；没有页面可见性判断 | 所有资料不再排队/处理中，或离开该页面 | web/main.tsx，Knowledge组件的loadDocs及定时effect |
| 新群接入 → 任务/机器人确认 | 当前读取、接入、问候、检查任务进行中，或接入完成但仍等待ready；每次响应后约2秒查询任务，必要时查询父流程及列表 | 任务完成/确认ready、请求失败、离开页面，或15分钟自动更新窗口到期；手动读取/重新选择可续期开启 | web/group-onboarding.tsx，readSelection、pollUntil及定时effect |
| 总管理员 → 待审核人数/菜单提醒 | 初次挂载及窗口重新获得焦点且页面未隐藏时读取/users；菜单/分组打开亦可触发一次读取 | 非总管理员不请求；这不是固定周期轮询 | web/use-pending-user-reviews.ts，refresh及focus监听 |

## 容易混淆但并非数据自动刷新的定时行为（未修改）

- API Key明文展示：30秒后自动隐藏；窗口失焦或页面可见状态变化时也隐藏（web/key-vault.tsx）。不会重查Key。
- 操作提示：4.5秒自动关闭（web/main.tsx）。
- 请求超时：群配置确认查询10秒中止，话题AI助填110秒中止（web/use-group-status.ts、web/topic-ai-assist.tsx）。这些是请求截止时间，不是刷新周期。
- 群配置确认目前手动；注册审核状态首次读取后也由按钮手动刷新。Persona/讨论等页面没有发现周期性数据读取。

服务端worker、运行端心跳/消息监听/发送队列属于后台工作机制，不是浏览器页面刷新，本次没有调整。
