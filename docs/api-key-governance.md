# API Key 归属、授权与费用管理

## 入口与密钥可见性

左侧「API Key 管理」包含我的 Key、站点公用 Key、申请与授权、用量与费用；总管理员另有全站 Key。原「模型配置」继续管理默认/分阶段路由。

- 私有 Key 归指定用户；公用 Key 由添加它的管理员所有，需明确授权给其他用户。
- 列表、下拉框及管理接口仅返回末6位。只有 `owner_user_id` 等于当前登录用户的独立 POST reveal 接口可返回完整密钥；管理员没有例外。响应 no-store、CSRF、审计，不把完整密钥放入列表、日志或浏览器持久存储。
- 所有人点击眼睛展开，30秒、窗口失焦或页面隐藏后收起。非所有人的眼睛禁用。管理员可以代用户添加私有 Key，保存后同样不能展开或更换该用户的密钥/接口/公私归属。
- Key 的元数据可由所有人（具模型管理权限）或总管理员维护。停用/归档保留账本；有账本后不能更改币种。公开资源共享不包含 Key。

## 公用申请与授权

用户选择自己的机器人、模型、功能、申请额度和用途；管理员批准时设置用户、机器人/群范围、模型名单、功能名单、到期时间、每日/每月次数与 token 上限，以及可选的费用预算和并发上限。也可以直接分配、调整、撤销。注册审核、业务权限、机器人分配与 Key 授权彼此独立。

不勾选机器人/群表示该用户的全部获准机器人/群；模型和功能必须显式选择。限制了群的授权不能用于无群上下文的 Persona/话题等任务。普通用户的模型下拉框过滤已获授权模型和功能；实际请求再次检查，不能用猜测 ID 绕过。

自动群任务按机器人当前所有人计算授权和消耗；管理员在他人空间操作也不能绕过私有 Key 归属。机器人转交后不会自动转交付费权限。Key 停用、用户停用、授权撤销/过期、群版本变化会拒绝后续调用；已发往服务商的请求可能已经计费。

删除站点账号前必须先归档其名下Key；删除后Key不转交、不擦除账本，保留原所有人并禁止重新启用。收到的公用授权撤销，同一GitHub再次注册的新用户不继承。详见[用户管理](users-and-permissions.md)。

## 调用与预算

后台话题生成、Persona、讨论分析、总结、互动、接入助手及 MaiBot 群回复均通过统一计量服务。运行端只领取75秒、绑定机器人/群/模型/Key版本的加密代理凭据，通过 GroupDesk 转发 OpenAI Chat/Responses 和 Gemini 原生协议（含流式）；不再下发服务商的原始 Key。未配置模型会停止调用，不沿用旧运行端 Key。

额度事务对 Key 加锁，在实际发送前检查授权并预留次数/token/估算费用；并发预留共享同一账本。预留采用请求 UTF-8 字节数的两倍加2048协议余量和单次输出上限，单次输出最多32768 token；按所设最高单价预留，返回服务商 usage 后按输入/输出/缓存结算。Gemini 思考量计入输出，已含思考的 OpenAI output 不重复相加。每次重试独立入账。

价格由所有人/管理员按模型、币种和每百万 token 填写，支持输入、输出、缓存输入；费用预算必须有对应价格；历史未定价且无金额预留的用量须先核对，不能当零费用开始预算。站点预算按配置价格估算，不能替代服务商账单或涵盖未配置的额外收费。公用 Key 首版只允许可计量的文字和函数工具调用；多媒体和服务商托管付费工具需要另外适配，当前拒绝。生图仍只配置 Key/模型，不新增群内生图功能。

未知 usage、响应丢失或发出后失败不当作零费用，保留预留量等待核对；发送前失败释放预留。中断20分钟的请求转为待核对，不永久占用并发槽。Key 所有人或总管理员可根据服务商账单核对未知/未定价记录，保留审计；获准使用公用 Key 的普通用户不能自行修改站点账本。

日/月额度以 Asia/Singapore（北京时间同 UTC+8）计算；提醒阈值默认80%可调整。用量页包含完整本月汇总、额度使用/预警和最近1000条明细，可按 Key、用户、机器人、群、模型、功能查看；不同币种分别汇总，不混加。汇总明确标注已确认部分与未定价/待核对笔数，全未定价时金额为待核对，不显示0费用。此 token 是模型用量，与摸鱼娱乐积分独立。

## 数据与迁移

024_key_vault_bot_control.sql 只在控制库创建 managed_model_keys/requests/grants/usage；025_key_vault_alias.sql 为机器人业务库添加 vault_key_id。原 Key 在服务器内解密后立即用控制面主密钥重封装，私有归原机器人所有人；同所有人/接口/协议/密钥合并为一份治理记录，原本地 ID 和群/功能路由不变。业务库原密文改为不可解密的 vault:v1 标记，不保留第二份可用秘密。模型配置复制只复制治理引用，不复制秘密或授予使用权。

部署需备份两个业务库与外部加密主密钥，并更新 app、后台 worker、互动 worker；不需重启微信/Reader/MaiBot。回退旧版本需在受控服务器内从Vault重封装旧业务密文，或恢复原模型行备份，不能让旧代码读取 vault:v1；不要直接全库恢复覆盖新增业务记录。迁移验证比较实际密钥摘要、原模型目录与路由，输出仅成功/数量，禁止输出密钥。真实服务商 Key 不用于隔离测试。
