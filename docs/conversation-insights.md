# 讨论语境、接梗与素材统计

群管理中的「玩笑识别与接梗」按群保存：语境识别、是否接梗、少量/适量/积极的频率倾向及补充规则。默认关闭，旧群不会自动改变。启用后沿用本群文字模型与Persona理解最近上下文；认真问题正常回答，混合语气先处理实质内容，无法确定时追问或旁听，澄清/不适/停止信号立即终止玩笑。历史玩笑不成为人物事实。

频率倾向是模型指导，不是准确的发言概率。针对原本未命中话题或基础社交的消息，原生适配器另提供有限的Planner判断机会：少量/适量/积极分别最多每群180/120/60秒一次，且按消息标识确定性抽取25%/50%/100%。这些是识别机会，不保证发言；仅话题参与模式且非安静时有效。全话题限制仍须命中已选话题。原有预算、频率、消息有效期和发送门控继续生效；未调用独立的逐消息分析API。

「讨论与接梗」统计的是已存档的数据集，不是实时全群监控。先选群和数据集、API Key/模型，再手动分析下一批（默认40、上限100）尚未标注或已变化的正文。每20条一次请求，单条正文最多2000字符，截断有标记；不把账号和引用原文送给分析服务。数据库保留素材和来源哈希，任务完成或失败后清空重复的输入正文。任务不自动重复计费请求，状态仅手动刷新。

每条独立标注语气（认真/玩笑/混合/不确定）及是否有实质内容；幽默也可有实质内容，认真也不保证有信息。低于60%置信度的模型结果保留为不确定。实质讨论占比=明确有实质内容的条数/(明确有+明确无)，暂不确定不计入分母；界面同时显示分析覆盖、未知数及素材日期。部分覆盖的数值不能说成整个群或整个话题的比例，不按时长计算，也不生成成员质量排名。

Gemini分析显式请求application/json输出，参考[官方GenerationConfig](https://ai.google.dev/api/generate-content#v1beta.GenerationConfig)；本地继续严格校验编号、字段、类别和置信度，不把JSON模式当作结果正确的保证。允许完整包裹的JSON代码块，拒绝夹杂解释正文。失败时分别提示JSON、结构字段或数据库错误代码，不记录/回显模型正文或私有聊天。

人工纠正带版本检查，更新统计但不改原文或Persona。同一正文的人工纠正不会被AI覆盖；源内容哈希变化则旧标注失效，新的分析独立处理。排除的素材、过滤后不匹配的记录不计数。

数据集支持按发送者账号、日期和「正文包含任一关键词」联合筛选。关键词按Unicode规范化、忽略大小写、规范连字符，英文词有边界，不按子串把不同姓名合并；不搜索他人引用。增量导入会自动纳入新的匹配正文，生成任务冻结筛选器和来源哈希。专项训练使用独立Persona草稿，人工审阅后再发布/绑定；这仍是Skill归纳，不是微调模型参数。

迁移010只增加关键词字段及分析任务/标注表，不更改旧群版本和现有人设。启用语境配置后需conversation_policy_version=1的适配器确认。原生安装器校验policy.py基线并幂等加入唯一接梗判断入口；banter.py与groupdesk_runtime.py同批更新，只重建MaiBot和桥接，不重启微信。发布沿用oc-push、隔离生产PR及Docker流程。

普通worker同时处理Persona和语境分析，需访问管理员选中的公网HTTPS模型服务。它连接数据库internal隔离网及独立model-egress桥接网，不加入共享edge网络，也不发布对外端口；模型传输继续校验公网地址、固定DNS解析结果并验证TLS。新增出站权限已获管理员明确授权，沿用既定PR及Docker流程发布。失败任务不自动重试，恢复连接后由管理员重新发起。

## 连续回复与跟进参数

群配置中的「连续回复与跟进」控制实际执行的轮数、重置间隔、同一成员的免点名跟进窗口，独立于下方玩笑识别开关。按群保存，不修改全局默认文件；初始值沿用2轮、180秒重置、180秒跟进，也可单独关闭轮数限制。仍须等待机器人确认配置版本。详细语义、迁移与原生部署见[integration/maibot/reply-limits/README.md](../integration/maibot/reply-limits/README.md)。
