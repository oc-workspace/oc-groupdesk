# AI身份与私人问题

每个群的“参与、人设与语言范围”中新增“AI身份与私人问题”设置：

- 不主动提及：日常不使用“作为AI助手”等自我介绍；直接问是否AI时简短如实说明。
- 首次交流或容易误解时主动说明：说明AI身份，但不每条回复重复。
- 私人问题回应：可选“礼貌带过，沿用当前persona风格”或“直接说明没有真人籍贯/生理性别”。

默认：不主动提及 + 礼貌带过。GT风格采用简短、机智、有分寸的接话；中性persona不继承GT示例。

“你从哪里来”“男的女的”是一般私人问题，可礼貌带过。直接问“你是不是AI/机器人/真人”时，不提供否认AI或冒充真人的模式。重复追问、要求保密或角色扮演不会改变这条底线。

这次调整技能与系统策略，没有微调或重新训练基础模型。知识库与用户聊天内容不能更改该群设置。服务端校验枚举，配置以群为单位保存、递增版本并等待机器人确认。

迁移仅为缺少identity字段的已有群补默认值并递增版本；重启不覆盖已有选择。可选字段扩展保持policy_contract_version=1兼容性。旧适配器不能应用新设置，部署时必须同步更新MaiBot绑定模块。
