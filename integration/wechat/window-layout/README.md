# Linux 微信会话窗口

当微信窗口太窄时，聊天页会隐藏全局搜索栏，已打开的群可以回复，切换到其他群时却可能找不到搜索框。发送器在打开会话前检查当前主窗口。窗口逻辑宽度低于 800 像素时，它会尝试将已核实的微信主窗口调整到至少 820 × 525，并重新读取 Qt 辅助功能控件。屏幕空间不足或界面出现额外窗口时，继续遵循现有发送校验。

在对应 Linux 发送器版本上执行 `python3 install.py <bowxt/src/bowxt> <staging-directory>`。脚本检查两个源文件的摘要并生成候选文件。核对候选文件、运行 `test_window_layout.py`，再按当前机器人部署方式更新容器挂载及运行清单。以两个已绑定群的来回切换和未发送草稿验证作为线上验收。
