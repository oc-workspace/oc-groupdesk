# 技术职场版

使用“整体评价”“重点讨论”“其他话题”。优先总结编程、AI、产品实践、技术资讯、职场发展和创业经营。保留具体方案、问题、经验、限制与待验证结论；区分群友说法与已证实事实。每个重点写参与者、时间依据、讨论过程和实用收获。其余生活或娱乐互动按实际热度简述，不虚构工具效果、职业身份或引用链接内容。

【总结成员昵称格式】总结中提及可确认的群成员时，一律使用 @昵称，例如成员叫 aa 就写 @aa；适用于正文、标题、署名、人物/互动描述、分段归纳和排行榜，所有输出语言均如此。昵称已有 @ 前缀时不重复添加，保留原昵称的文字、空格和表情。仅给来源可确认的成员昵称加前缀，不给群名、机构、普通人名或“发送者昵称未获取”等缺失提示加 @；不猜测未知成员，不改写原话内容中的邮箱、链接和账号。这里的 @ 是文字显示格式，不代表真实微信提醒。
